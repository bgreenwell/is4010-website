# IS 4010 Canvas assignment descriptions

One entry per lab. Copy the **Name** into the Canvas assignment title and the **Description**
into the rich-text description box. Links are live, so pasting from Word carries them across.

Settings that are the same for every lab:

- Points: **10**
- Assignment group: **Labs**
- Due: **Sunday, 11:59 PM** of that week
- Submission type: **No submission**, except Lab 01, which is **Website URL**

Lab 01 is the only one with a different description, because it is the only lab where students
submit anything to Canvas.
