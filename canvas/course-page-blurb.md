## About this course

This course teaches you to program in Python and then in Rust, and to work well with AI
coding assistants while you do it. You will write code that processes data and implements
real algorithms, in the tools professional developers use: VS Code, the terminal, Git and
GitHub, and command-line AI agents.

The first half is Python: data structures, functions, error handling, and object-oriented
programming, applied to programs that read files and pull live data from web APIs. The
second half switches to Rust, a compiled language with a much stricter model of memory and
ownership. Learning it will change how you read the Python you wrote earlier in the term.

Fourteen hands-on labs and a solo capstone project. Every lab is checked automatically when
you push it, so you find out in minutes whether it works.

One principle governs the course: you are the pilot and AI is the co-pilot. You are
responsible for every line you submit, and you must be able to explain it.

## Course website

Bookmark this: **[bgreenwell.github.io/is4010-website](https://bgreenwell.github.io/is4010-website/)**

I organize the term into modules here in Canvas, and Canvas is where you'll find due dates,
grades, and announcements. The course materials live on the course website.

Every week has a page on the site with:

- Lecture slides
- An interactive notebook you can run and edit (Weeks 2 to 8)
- Links to that week's readings
- A link to that week's lab

The site also has the setup guide, a troubleshooting page, a survey of free AI tools, and
the final project specification.

It is public and needs no login, so you can read ahead, review after class, and work from
any machine. I will link to specific pages from the modules, but bookmarking the site is
faster than clicking through Canvas every time.
